# RHC7 — 20 игровых пропсов из сканов скелетов

Набор из **20 очищаемых объектов**: 10 частей T. rex и 10 частей/областей черепа Triceratops. Вырезаны из двух реальных сканов (`Assets/Models/Skeletons_Real`) и сохранены отдельными FBX + общим GLB.

> **Важно:** это **20 игровых пропсов**, а не 20 отдельных анатомических костей. Сканы спаяны/фрагментированы, поэтому часть объектов — целые группы (лапа, шея) или области внутри fused-черепа. Подробности в разделе «Ограничения».

## Файлы

```
Assets/Models/Bones_Real/
  Trex_*.fbx                     — 10 отдельных частей T. rex
  Triceratops_*.fbx              — 10 отдельных частей Triceratops
  RHC7_RealBoneSet.glb           — все 20 объектов, текстуры встроены
  RHC7_RealBoneSet.fbx           — все 20 объектов, текстуры внешние
  README.md
```

- Отдельные FBX: origin в центре X/Y, низ на Z = 0, Y-up, масштаб 1:1 в метрах.
- Текстуры не встроены в отдельные FBX: они лежат в `Assets/Models/Skeletons_Real/Textures/`; FBX ссылается на `../Skeletons_Real/Textures/...`. В Unity текстуры находятся в проекте и подхватываются по имени.
- Общий GLB содержит все текстуры внутри (4K Triceratops + 2K T. rex).
- Сцена Blender: `Blender/RHC7_BoneSet_Real.blend` (20 объектов расставлены сеткой, оригинальные скелеты скрыты).
- Превью: `Screenshots/bones_real_20_sheet.png`, `Screenshots/bones_real_20_grid.png`, отдельные рендеры в `Screenshots/BoneSet/`.

## Источники и лицензии

- **T. rex** — скан реплики из Knuthenborg Safaripark, автор **Rigsters** (<https://rigsters.com/>), **CC BY 4.0**. Источник: Wikimedia Commons `File:Tyrannosaurus rex skeleton.stl`. Атрибуция обязательна.
- **Triceratops** — Smithsonian Institution, NMNH, USNM PAL 500000 («Hatcher»), **CC0**. Текстурированный GLB — Innerscene 3D Parts Library (CC0). Указание Smithsonian желательно.
- Текстуры T. rex (2K bone albedo/normal/roughness/AO) сгенерированы в проекте RHC7.

## Unity

- Импорт FBX: Scale Factor = 1, Y-up.
- Материалы FBX: base color + normal; roughness/AO — отдельные карты в `Skeletons_Real/Textures`. Для URP Lit назначить roughness в metallic/smoothness (A) или использовать `RHC7/Bone Cleaning`.
- Origin внизу: объект ставится на стол/пол без смещения.
- UV есть у всех частей; у T. rex UV повторены 3× (Smart UV), у Triceratops — оригинальные UV скана.
- Для столкновений — упрощённый MeshCollider/боксы; 67k треугольников на 20 объектов нормально для статичных пропсов.

## Ограничения

- **Это не 20 отдельных анатомических костей.** T. rex-скан спаян в 6 кусков: череп не отделяется чисто, поэтому в наборе нет T. rex-черепа; `Trex_Neck` — шея/спина, `Trex_Hindlimb_L` — целая задняя лапа, `Trex_Forelimb_*` — целые передние лапы, `Trex_Pelvis` — тазовая область, `Trex_TailVertebra` — участок хвоста.
- Triceratops-скан — 2 087 фрагментов поверхности. `Triceratops_Skull` — целый череп; остальные 9 объектов — **области того же черепа** (воротник, челюсть, рог, зубной ряд и т.д.), они пересекаются с черепом и не являются отдельными костями.
- Границы вырезанных объектов открытые (нет торцевых крышек); для очень крупного плана нужен retopo/cap.
- Для настоящего набора из 20 отдельных костей нужна предварительно сегментированная анатомическая модель; из fused-сканов автоматически её не получить.

## Что можно улучшить

1. Заменить T. rex-части на предсегментированную модель с отдельными черепом/челюстью/позвонками.
2. Разделить Triceratops-череп на непересекающиеся кости вручную (долгая ретопология).
3. Добавить торцевые крышки и decimate до 5–10k на объект для мобильной версии.
