# RHC7 · данные игры

Все игровые образцы и страницы книги теперь описываются ScriptableObject-ассетами. Логика не знает, сколько костей в смене: количество образцов, слотов левого ящика и кнопок книги берётся из данных.

## Структура

- `Specimens/*.asset` — описание образца:
  - `id`, `partName`, `hint`;
  - `species` — существующий вид;
  - `bonePrefab` **или** `completeMesh`;
  - `cratePosition`, `crateEuler`, `prepEuler`;
  - `visualScale` — масштаб модели;
  - `tagText` — готовая надпись на бирке.
- `Species/*.asset` — страница книги:
  - отображаемое имя, вид;
  - заголовок и описание;
  - `mainArt` и `extraArt`.
- `Levels/*.asset` — состав смены:
  - `cleanThreshold`;
  - список `specimens`;
  - список `species`.
- `JSON/*.json` — читаемые копии уровней для сдачи/ревью. Они не подменяют ScriptableObject, а показывают структуру данных и разницу между базовой и демо-сменой.

## Готовые уровни

- `BaseLevel.asset` — три кости основной игры.
- `DemoLevel.asset` — та же смена плюс большая кость `TrexPelvis`; показывает расширение через данные.
- `InvalidLevel.asset` — намеренно битые записи для проверки валидатора.

## Как добавить новую кость без изменения кода

1. Создайте или скопируйте `SpecimenDefinition` в `Assets/Data/Specimens`.
2. Укажите `id`, `partName`, существующий вид, префаб/меш, позиции и текст бирки.
3. Откройте `Assets/Data/Levels/DemoLevel.asset` и добавьте новый ассет в `specimens`.
4. Запустите **Tools → RHC7 → Build Data Demo (4 bones)**.
5. Количество слотов левого ящика и завершение смены пересчитаются автоматически.

Исходный код менять не нужно. Для новой кости того же вида дополнительная страница книги не требуется: книга определяет вид, а бирку берёт из `tagText`. Текущий разворот книги рассчитан на два вида; добавление третьего вида — отдельная задача расширения страниц.

## Проверка ошибок

Сцена `Assets/Scenes/RHC7_ConfigValidation.unity` использует `InvalidLevel.asset`:
- пустой образец;
- повторяющийся `id`;
- отсутствующий вид;
- неизвестный вид у образца.

`LevelValidator` собирает отчёт, отбрасывает невалидные записи и не даёт одной ошибке сломать остальные данные. Отчёт виден в окне проверки.

## Сцены

- `Assets/Scenes/RHC7_PrepGame.unity` — основная игра, 3 кости.
- `Assets/Scenes/RHC7_DataDemo.unity` — демонстрация расширения, 4 кости.
- `Assets/Scenes/RHC7_ConfigValidation.unity` — отчёт по ошибочному набору данных.
- `Assets/Scenes/RHC7_InvalidDataGame.unity` — та же игра, запущенная с безопасным подмножеством невалидного конфига.

В Build Settings добавлена только основная сцена; демо-сцены открываются в редакторе отдельно.
