# РХЦ-7 — прототип ядра чистки

Проект Unity **6.0.76f1**, рендер **URP**, камера на **Cinemachine**.

Сцена для запуска: **`Assets/Scenes/CleaningCore.unity`**. Откройте её и нажмите **Play**.

Одно-костный прототип чистки черепа Triceratops — **`Assets/Scenes/RHC7_SimpleTable.unity`** (см. раздел «Простой стол: чистка черепа Triceratops»).

## Что уже играбельно

- Три кости по очереди: **бедро** (песчаник), **плечевая** (глина), **большая берцовая** (известняк). После очистки текущей автоматически появляется следующая.
- Инструменты на стойке справа: **кисть, скребок, зубило**. Клик по инструменту — взять его.
- **Два слоя породы:** верхний (безопасный) и нижний (опасный). Граница — 50 % грязи.
- **Обучение первой кости:** три шага, золотая подсветка выбранного инструмента на стойке, вспышка при смене слоя и подсказка о переходе к следующей кости.
- Чистка зажатой ЛКМ: грязь стирается по UV-маске, скорость мыши ускоряет снятие, но сильнее изнашивает кость.
- Износ: царапина → скол (−10 %) → трещина (−15 %) → разрушение (кость распадается).
- Лупа на ПКМ (приближение + затемнение по краям).
- Колесо **на столе** — приблизить/отдалить; колесо **над костью** — повернуть кость, чтобы очистить бока и низ.
- В конце третьей кости: «Рабочий акт» с прогрессом, износом и оценкой. Кнопка «ПРОЙТИ ЗАНОВО» запускает серию заново.
- Процедурные текстуры и меши: дерево, сукно, бумага, лампа, кость.

## Управление

| Действие | Управление |
|---|---|
| Чистить | зажать ЛКМ и водить по кости |
| Лупа | зажать ПКМ |
| Приблизить / отдалить | колесо, когда курсор не над костью |
| Повернуть кость | колесо, когда курсор над костью (35° за щелчок) |
| Взять инструмент | клик по инструменту на стойке |
| Начать заново | кнопка «СБРОС» или R |

**Важно:** управление работает, когда окно игры в фокусе. При входе в Play Game view фокусируется автоматически. Если видите тёмный экран с надписью «КЛИКНИТЕ ПО ОКНУ ИГРЫ» — кликните по Game view один раз, и управление включится.

## Где крутить баланс

- Выберите объект **`Game`** в сцене:
  - `removalScale` — общая скорость снятия породы;
  - `wearScale` — общий износ;
  - `uvAspect`, `boneCircumference` — геометрия пятна контакта.
- Инструменты: `Assets/Scripts/Cleaning/ToolDefinition.cs` — `removal`, `wear`, `radiusUV`, `softness`.
- Слои, пороги и повреждения: `Assets/Scripts/Cleaning/BoneSurface.cs`:
  - два слоя по остатку грязи: `> 0.50` верхний, иначе нижний;
  - множители снятия/износа — в `Paint`;
  - пороги повреждений: `ScratchThreshold`, `ChipThreshold`, `CrackThreshold`, `DestroyThreshold`.
- Цвета кости и породы: материал `Assets/Materials/Bone.mat` (шейдер `RHC7/Bone Cleaning`).
- Свет и постобработка: объекты `DeskLamp`, `WindowFill`, `Global Volume`; профиль `Assets/Settings/RHC7_Post.asset`.

## Пересборка сцены

Меню **`RHC7 → Rebuild Cleaning Core Scene`** (или `PrototypeBuilder.BuildAll()` через MCP).
Скрипт создаёт меши, текстуры, материалы, сцену и добавляет её в Build Settings. Он перезаписывает `Assets/Scenes/CleaningCore.unity` и профиль постобработки.

## Проверка на одном и том же месте

- **Кисть** — `radiusUV 0.12`, мягкая, снимает **2,05 %** маски за один короткий проход.
- **Скребок** — `0.045`, снимает **0,29 %**; после 2,2 с на контактном слое даёт **трещину** (износ 77 %).
- **Зубило** — `radiusUV 0.08`, широкий скос: быстро снимает плотную породу; долгое удержание на одном месте даёт трещину.
- Для сравнения: кисть за 3 с даёт 12 % износа без повреждений.
- Износ теперь хранится в точном float-буфере: медленные прибавки больше не теряются из-за округления 8-битной маски.
- Кольцо курсора всегда показывает реальную зону инструмента; у зубила это заметный круг, а не точка.
- Кнопка **«СБРОС»** на HUD сбрасывает кость мышью, не требует клавиатуры.
- Финальный порог «очищено» — 82 % фактической грязи: остаток у UV-шва и на обратной стороне полируется автоматически, иначе финал был недостижим. HUD показывает 100 %.
- После очистки кость блокирует дальнейший износ: повторные проходы не могут её разрушить.
- Модели инструментов масштабированы под радиус: широкая кисть, средний скребок, широкое зубило; радиус действия пересчитывается под окружность каждой из трёх костей.
- Два слоя: верхний (`dirt > 0.5`) безопасный, нижний — износ ×2.5; HUD показывает «верхний слой» / «нижний слой».

## Три кости

1. **Бедро** — песчаник, коричневая порода.
2. **Плечевая** — глина, красноватая порода.
3. **Большая берцовая** — известняк, серо-каменная порода.

После очистки текущая кость **ждёт определения по атласу**: игрок открывает книгу, выбирает вид и прикрепляет ярлык, только потом появляется следующая. При разрушении кости атлас пропускается. HUD показывает `КОСТЬ N / 3`, название и ярлык; после третьей открывается «Рабочий акт» с числом верных определений. Кнопка «СБРОС» и **R** сбрасывают текущую кость.

## Простой стол: чистка черепа Triceratops

- Сцена **`Assets/Scenes/RHC7_SimpleTable.unity`** (Build Settings, после `CleaningCore`; `CleaningCore` не тронута).
- Один экспонат: **череп Triceratops** (`Assets/Models/Bones_Real/Triceratops_Skull.fbx`) с оригинальными 4K PBR-текстурами Smithsonian. Череп лежит на каменной подставке с тканевой подушкой; рядом лежат кисть, скребок и зубило.
- Грязь **трёхслойная и неравномерная**: пыль (R), глина (G), кора (B), износ (A). Слой хранится в **3D-текстуре 160³** в объектном пространстве, поэтому рисунок не зависит от фрагментированной UV-развёртки скана. Начальная грязь — процедурный fBm: крупные пятна, натёки, оголённые участки кости; скрытый низ черепа не засыпан.
- Инструменты: **кисть** снимает пыль, **скребок** — глину, **зубило** — кору. Неподходящий инструмент почти не снимает слой и быстрее изнашивает кость. Смена — **1/2/3** или кнопками внизу.
- Чистка: зажать **ЛКМ** и водить по кости. Кисть снимает объём грязи вокруг точки; HUD показывает общий прогресс, остаток каждого слоя и износ. Кольцо курсора меняет цвет (зелёный / жёлтый / красный) по эффективности выбранного инструмента на текущем слое. При полной очистке появляется баннер **«КОСТЬ ОЧИЩЕНА»**.
- Управление: **ПКМ** — орбита камеры, **колесо** — зум, **Q/E** — поворот кости вокруг вертикали, **R** — сброс.
- Шейдер **`RHC7/Natural Bone Dirt`** (`Assets/Shaders/BoneDirtLayers.shader`) смешивает реальные albedo/normal/AO черепа с процедурной грязью, даёт слоистый вид, микрорельеф и износ. Маска чистки — `_DirtVolume`, границы объёма — `_VolumeMin` / `_VolumeSize`.
- Скрипт **`Assets/Scripts/Cleaning/NaturalBoneCleaning.cs`**: генерация объёма, сэмплы поверхности для прогресса, объёмная покраска, HUD, частицы, камера.
- Превью: `Screenshots/final4_dirty_ui.png` (грязный череп), `final4_dustoff.png` (пыль снята), `final4_partial_ui.png` (частичная чистка), `final4_clean_ui.png` (готово).

### Настройка чистки на SimpleTable

- Объект **`DirtCleaningGame`**: `maskSize = 160` (разрешение 3D-маски), `removalScale = 2.6` (общая скорость), `wearScale = 1`, `supportSink = 0.045`, `cameraDistance = 1.05`.
- Инструменты — `BuildTools()` в `NaturalBoneCleaning.cs`: `radiusLocal` (радиус пятна в локальных координатах черепа), `softness`, `effectiveness` по слоям (пыль/глина/кора), `wearRate`.
- Материал **`Assets/Materials/DirtCleaning/SkullDirt.mat`**: цвета слоёв, `_DustOpacity`, прочность процедурного рельефа; текстуры черепа — `_BoneAlbedo`, `_BoneNormal`, `_BoneAO`.
- Порог завершения — **2 %** остаточной массы; баннер и 100 % в HUD срабатывают после него.
- Сцена `CleaningCore` и её скрипты не изменялись; это отдельный одно-костный прототип.

## Обязательная смена инструмента

- **Песчаник** — кисть работает.
- **Глина** — кисть работает хуже, скребок быстрее.
- **Известняк** — кисть снимает лишь **2 %** от обычной скорости, скребок — **15 %**, зубило — **115 %**. При кисти/скребке на третьей кости появляется подсказка «ИЗВЕСТНЯК · НУЖНО ЗУБИЛО», и без зубила кость не очистить.

## Атлас и ярлыки

- На столе слева лежит **книга-атлас**; после очистки кости она подсвечивается.
- Клик по книге открывает атлас: три вида — Теропод, Цератопс, Зауропод — с описанием формы, размера и породы.
- Выбранный вид прикрепляется как ярлык; HUD показывает его в строке «ЯРЛЫК».
- После ярлыка появляется следующая кость; в финальном акте выводится «Верно определено: X / 3».

Скриншоты: `Screenshots/atlas_open.png`, `limestone_hint.png`, `atlas_final.png`.
