# РХЦ-7 · Подготовка

Небольшая 3D-игра в Unity о препарации музейных костей в лаборатории 1930-х годов.

Игрок достаёт кость из ящика, очищает её слои правильными инструментами, определяет породу по книге-определителю и отправляет образец с бумажной биркой в отдельный ящик коллекции.

## Как запустить

1. Установите **Unity 6.0.76f1** (Unity 6000.0.76f1) с поддержкой **URP**.
2. Откройте папку проекта `RHC7` через Unity Hub.
3. Откройте сцену **`Assets/Scenes/RHC7_PrepGame.unity`**.
4. Нажмите **Play**.

Если сцена не открылась или нужно пересобрать её с нуля:
**Tools → RHC7 → Build Prep Game**.

## Управление

| Действие | Управление |
|---|---|
| Открыть ящик / выбрать кость | ЛКМ |
| Взять инструмент | ЛКМ по инструменту на лотке |
| Чистить кость | зажать ЛКМ и вести по поверхности |
| Приблизить / отдалить | колесо мыши |
| Вращать кость | ПКМ или СКМ |
| Крен кости | Q / E |
| Сбросить позу кости | R |
| Открыть книгу после чистки | ЛКМ по книге на столе |

## Игровой цикл

1. Открыть ящик и взять одну из трёх костей.
2. Снять пыль кистью, глину скребком, матрицу — зубилом с молотком.
3. После достижения порога чистки на записке появляется подсказка открыть книгу.
4. Открыть книгу на столе и определить породу по иллюстрациям и описаниям.
5. После верного ответа на кость вешается бирка с породой и частью скелета.
6. Кость автоматически перемещается в левый ящик коллекции.
7. После третьей кости игра завершается.

## Что есть в проекте

- три очищаемые модели: череп тираннозавра, череп трицератопса, бедренная кость тираннозавра;
- слоистая система загрязнения с очисткой по точному лучу курсора;
- физические инструменты на лотке: кисть, скребок, пара «зубило + молоток»;
- анимации удержания и работы инструментов;
- бумажная памятка с инструкцией и прогрессом;
- книга-определитель с изображениями и описаниями;
- два одинаковых ящика: исходный справа и ящик коллекции слева;
- бумажные бирки, которые появляются на определённых костях;
- интерьер лаборатории 1930-х: паркет, дубовые панели, высокие окна, радиаторы, латунь, старые светильники.

## Основные файлы

- `Assets/Editor/PrepGameBuilder.cs` — сборка комнаты, мебели, инструментов, книги и игровых объектов.
- `Assets/Editor/NoteImageBuilder.cs` — рендер картинок костей и инструментов для книги.
- `Assets/Scripts/Game/GameFlow.cs` — игровой цикл, камера, ящики, книга и завершение.
- `Assets/Scripts/Game/BoneCleaningV2.cs` — очистка, слои грязи, зум и вращение кости.
- `Assets/Scripts/Game/ToolShelfInteraction.cs` — выбор инструментов и анимации.
- `Assets/Scripts/Game/PrepNoteUI.cs` — бумажная памятка.
- `Assets/Scripts/Game/SpecimenTag.cs` — бирка определённой кости.
- `Assets/Scenes/RHC7_PrepGame.unity` — основная сцена.
- `Assets/Textures/Notes/` — изображения для книги-определителя.

## Сборка

1. **File → Build Settings**.
2. В списке сцен должна быть только `Assets/Scenes/RHC7_PrepGame.unity`.
3. Выберите платформу **Windows** (или другую нужную) и нажмите **Build**.

## Для друзей / переноса проекта

Для редактирования передавайте папку проекта целиком **без** `Library`, `Temp`, `Logs`, `obj` и `UserSettings` — эти папки Unity создаст сама. Обязательно сохраните:

- `Assets/`
- `Packages/`
- `ProjectSettings/`
- `.gitignore`
- `README.md`

Внешние исходники и лицензии на модели находятся в `Blender/`, `Assets/Models/` и `Assets/Models/Skeletons_Real/README.md`. Перед публичной раздачей проверьте условия лицензий исходных сканов.
